## Objectif { #block-create-custom }

Créer un bloc affichant les horaires et la localisation du marché fermier.
## Prérequis

* [block-concept](./block-concept.md)
* [block-regions](./block-regions.md)
## Étapes

1. Dans le menu d'administration _Gérer_, aller à _Contenu_ > _Blocs_ (_admin/content/block_).
1. Cliquer sur _Ajouter un bloc de contenu_. La page _Ajouter un bloc
    de contenu_ apparaît.
1. Remplir les champs comme ci-dessous.
    <table>
      <thead>
        <tr>
          <th>Nom du champ</th>
          <th>Explication</th>
          <th>Valeur d'exemple</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td>Description du bloc</td>
          <td>Nom du bloc tel qu'affiché pour les utilisateurs</td>
          <td>Bloc</td>
        </tr>
        <tr>
          <td>Corps</td>
          <td>Contenu du bloc lorsqu'il est affiché</td>
          <td>Ouverture : le dimanche de 9 h à</td>
        </tr>
      </tbody>
    </table>

    ![Ajouter un bloc de contenu](/images/block-create-custom-add-custom-block.png)

1. Cliquer sur _Enregistrer_. Un message indiquant que le bloc a été enregistré
    apparaît.

## Pour approfondir

* Modifier le contenu du bloc personnalisé. dans le menu d'administration
_Gérer_, aller à _Contenu_ > _Blocs (_admin/content/block). Localiser votre
bloc dans la liste et cliquer sur _Modifier_ pour effectuer des changements.
* Placer le bloc que vous avez créé dans la barre latérale. Consulter
[block-place](./block-place.md) pour plus de détails.
