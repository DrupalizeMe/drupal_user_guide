## Zielsetzung { #user-new-user }

Erstellen Sie die Benutzerkonten für die Lieferanten „Sweet Honey“ und „Happy Farm“.
## Erforderliche Vorkenntnisse

* [user-concept](./user-concept.md)
* [user-admin-account](./user-admin-account.md)
* [user-new-role](./user-new-role.md)
## Anforderungen an die Website

Die Rolle Lieferant muss auf Ihrer Website vorhanden sein. Siehe [user-new-role](./user-new-role.md).
## Arbeitsschritte

1. Navigieren Sie im Menü _Verwalten_ zum Menüpunkt _Benutzer_ (_admin/people_).
1. Klicken Sie auf _Benutzer hinzufügen_.
    <img src="/images/user-new-user_form.webp" alt="Form for creating a new user account" width="100%" />
1. Füllen Sie die Formularfelder wie folgt aus. Siehe: Tabelle unten.
    <table>
      <thead>
        <tr>
          <th>Feldname</th>
          <th>Erläuterung</th>
          <th>Beispielwert</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td>E-Mail-Adresse</td>
          <td>Eine gültige E-Mail-Adresse für den Verkäufer. Alle E-Mails aus dem System werden an diese Adresse geschickt. Die E-Mail-Adresse wird nicht veröffentlicht.</td>
          <td>honey@example.com</td>
        </tr>
        <tr>
          <td>Benutzername</td>
          <td>Ein Benutzername für den Lieferanten, den dieser zur Anmeldung oder zum Verfassen von Inhalten verwendet. Leerzeichen sind erlaubt; Satzzeichen sind nicht erlaubt, mit Ausnahme von Punkten, Bindestrichen, Apostroph-Zeichen und Unterstrichen.</td>
          <td>Sweet Honey</td>
        </tr>
        <tr>
          <td>Passwort</td>
          <td>Ein Passwort, mit dem sich der Anbieter bei der Website anmeldet. Wie sicher das Kennwort ist, können Sie an der _Passwortstärke_ ablesen. Sie erhalten auch Tipps, wie Sie es sicherer machen können.</td>
          <td>(Erstellen Sie ein sicheres Passwort)</td>
        </tr>
        <tr>
          <td>Passwort bestätigen</td>
          <td>Geben Sie dasselbe Passwort ein, um Tippfehler zu vermeiden.</td>
          <td>(Passwort wiederholen)</td>
        </tr>
        <tr>
          <td>Status</td>
          <td>Status des Benutzerkontos festlegen. _Gesperrte_ Benutzer können sich nicht anmelden.</td>
          <td>Aktiv</td>
        </tr>
        <tr>
          <td>Rollen</td>
          <td>Rolle des Benutzerkontos festlegen.</td>
          <td>Lieferant</td>
        </tr>
        <tr>
          <td>Benutzer über neues Konto benachrichtigen</td>
          <td>Ob eine Benachrichtigung an die E-Mail-Adresse des Lieferanten gesendet werden soll oder nicht.</td>
          <td>Ausgewählt</td>
        </tr>
        <tr>
          <td>Bild</td>
          <td>Klicken Sie auf _Durchsuchen_ und wählen Sie ein Bild zum Hochladen aus. Achten Sie auf Größenbeschränkungen.</td>
          <td>Logo des Lieferanten</td>
        </tr>
        <tr>
          <td>Kontakteinstellungen</td>
          <td>Aktivieren oder deaktivieren Sie die Anzeige eines Kontaktformulars für das Konto.</td>
          <td>Ausgewählt</td>
        </tr>
      </tbody>
    </table>
1. Klicken Sie auf _Neues Benutzerkonto erstellen_. Es wird eine Meldung ausgegeben, dass das neue Benutzrkonto angelegt wurde.
    <img src="/images/user-new-user-created.webp" alt="New user account has been created" width="100%" />
1. Erstellen Sie ein zweites Benutzerkonto für den Lieferanten „Happy Farm“, indem Sie die oben angegebenen Schritte wiederholen.

## Vertiefen Sie Ihr Wissen

Erstellen Sie ein Benutzerkonto für sich selbst.
