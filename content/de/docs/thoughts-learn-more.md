### Wo können Sie mehr erfahren?

Die folgenden Ressourcen sollten sich für Sie als nützlich erweisen, wenn Sie Ihre Fähigkeiten weiter ausbauen möchten:

- [Der Bereich „Drupal Community Dokumentation" auf _Drupal.org_](https://www.drupal.org/documentation): Dies ist eine Wiki-ähnliche Dokumentation, die von der Drupal-Community bereitgestellt wird. Hier finden Sie grundlegende und tiefergehende Informationen, über alle Aspekte von Drupal (Site-Building, Verwaltung, Entwicklung von Themes, Entwicklung und bereitstellen von Modulen).
- [_api.drupal.org_](https://api.drupal.org): Die Referenzdokumentation für Programmierer zur Drupal-API.
- [„Drupal Planet"-Seite auf _Drupal.org_](https://www.drupal.org/planet): Eine Sammlung von Blog-Beiträgen über Drupal aus dem gesamten Web, gepostet von bloggenden Mitgliedern der Drupal-Community, deren Beiträge hier zusammengefasst werden. Die Themen reichen von Programmierung über Site-Building bis hin zu Neuigkeiten zu Drupal.
- **Gruppen, Veranstaltungen und Treffen:** Lesen Sie [thoughts-connecting](./thoughts-connecting.md), um mehr über aktuelle Gruppen, regionale Gruppen und Gruppen in Ihrer Muttersprache sowie lokale, regionale und internationale Veranstaltungen zu erfahren.
- [„Ausbildungsmarktplatz"-Seite auf _Drupal.org_](https://www.drupal.org/training): Der Marketplace listet kostenpflichtige Schulungsanbieter auf. Wenn Sie an kostenlosen Trainings interessiert sind, sehen sie nach auf welchen Veranstaltungen kostenlose Trainings angeboten werden. Auf folgender Seite finden Sie ebenfalls kostenlose oder sehr günstige Trainings: [„Global Training Days" auf _Drupal.org_](https://groups.drupal.org/global-training-days).
- **Support-Seiten:** Lesen Sie das Thema [thoughts-support](./thoughts-support.md) um Supportforen zu finden. Danach zu suchen kann nützlich sein, wenn Sie etwas über ein bestimmtes Thema lernen möchten.
