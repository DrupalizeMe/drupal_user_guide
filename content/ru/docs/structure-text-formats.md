## Что такое форматы текста и фильтры? { #structure-text-formats }

_Форматы текста_ изменяют то, как теги HTML и другой текст обрабатываются и отображаются
на вашем сайте. Форматы текста состоят из ряда _фильтров_, каждый из которых
трансформирует текст. Когда пользователи создают контент, с содержимым связывается
текстовый формат, и полный, исходный текст сохраняется в базе данных. Затем содержимое
пропускается через фильтры текстового формата перед выводом на
сайте.

Модуль ядра Filter обеспечивает функциональность форматов текста, а стандартный
установочный профиль создает форматы текста _Basic HTML_, _Restricted HTML_ и _Full HTML_.
Для каждого текстового формата есть соответствующее разрешение, чтобы вы могли
разрешить только доверенным пользователям использовать более свободные форматы текста. Это ограничивает
недоверенных пользователей такими форматами как _Basic HTML_, который фильтрует опасные
HTML-теги.
## Какие редакторы связаны с форматами текста?

Каждый формат текста может быть связан с редактором, например, визуальным WYSIWYG
(What You See Is What You Get — «Что вижу, то и получаю») HTML-редактором. Модуль ядра Text Editor
позволяет ассоциировать редакторы с форматами текста и настраивать их
(например, добавлять или убирать кнопки на панели инструментов). Модуль ядра CKEditor
предоставляет стандартный редактор CKEditor, чтобы он мог
использоваться для редактирования HTML-контента на вашем сайте.
## Что такое межсайтовый скриптинг?

Межсайтовый скриптинг (XSS) — это уязвимость безопасности, обычно встречающаяся на
веб-сайтах. На сайте без хорошей защиты злоумышленники могут вставить скрипт
на страницы, которые просматривают другие пользователи (например, в комментарии или
в основной текст страницы). Уязвимость межсайтового скриптинга может быть использована
злоумышленниками для входа как другой пользователь. Важно правильно настроить форматы
текста на вашем сайте, чтобы не допустить такой атаки.
