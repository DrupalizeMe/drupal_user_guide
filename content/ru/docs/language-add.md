## Цель { #language-add }

Добавить один или несколько языков на сайт и определить, какой язык будет использоваться по умолчанию.
## Необходимые знания

[language-concept](./language-concept.md)
## Шаги

1. Установите четыре основных многоязычных модуля (Language, Interface Translation, Content Translation и Configuration Translation), следуя инструкциям в [config-install](./config-install.md).
1. В административном меню _Управление_ перейдите в _Конфигурация_ > _Регион и язык_ > _Языки_ (_admin/config/regional/language_).
1. Нажмите _Добавить язык_.
1. Выберите _Spanish_ (или предпочитаемый вами язык) из списка _Название языка_. Нажмите _Добавить язык_. После загрузки переводов вы вернетесь на страницу _Языки_ с подтверждением и новым языком в списке.
    <img src="/images/language-add-list.png" alt="Список доступных языков на сайте" width="100%" />
1. Следуйте инструкциям из [block-place](./block-place.md), чтобы разместить блок _Language switcher_ в регионе _Sidebar second_. Это позволит посетителям сайта переключаться между языками, как только сайт будет переведен.
