## Цель { #extend-config-versions }

Синхронизировать конфигурацию между сайтом разработки и рабочим сайтом.
## Необходимые знания

* [understanding-data](./understanding-data.md)
* [install-prepare](./install-prepare.md)
* [install-dev-sites](./install-dev-sites.md)
* [install-dev-making](./install-dev-making.md)
## Требования к сайту

* У вас должна быть копия разработки вашего рабочего сайта. Смотрите
[install-dev-making](./install-dev-making.md).
* Модуль ядра Configuration Manager должен быть установлен как на сайте
разработки, так и на рабочем сайте. Смотрите [config-install](./config-install.md) для
инструкций по установке модулей ядра.
* Вы изменили конфигурацию либо на рабочем, либо на тестовом
сайте (_исходный сайт_) и хотите синхронизировать изменения с другим
сайтом (_целевой сайт_). Например, можно создать новый тип
контента, поля и представления на сайте разработки и,
убедившись в их правильной работе, развернуть изменения на рабочем сайте.
* Вся конфигурация, которую не нужно синхронизировать между исходным и
целевым сайтами, должна храниться в переопределениях конфигурации в файле
_settings.php_, а не в базе данных. Смотрите [install-dev-making](./install-dev-making.md).
## Шаги

1. На исходном сайте в административном меню _Управление_ перейдите в
      _Конфигурация_ > _Разработка_ > _Синхронизация конфигурации_ > _Экспорт_
      (_admin/config/development/configuration/full/export_).
1. Нажмите _Экспорт_. Сайт сформирует архив полной конфигурации.
      Сохраните файл на локальном компьютере.
1. На целевом сайте в меню _Управление_ перейдите в
      _Конфигурация_ > _Разработка_ > _Синхронизация конфигурации_ > _Импорт_
      (_admin/config/development/configuration/full/import_).
1. Найдите скачанный архив конфигурации и нажмите _Загрузить_. Файл будет
      загружен, после чего вы перейдёте на страницу _Синхронизировать_
      (_admin/config/development/configuration_), где появится сообщение
      об успешной загрузке файлов.
1. Убедитесь, что показанные отличия соответствуют ожиданиям. Будут
      отображены элементы конфигурации, которые добавлены, удалены или изменены;
      для изменённых элементов можно нажать _Просмотреть отличия_, чтобы увидеть
      конкретные изменения.
1. Когда всё проверено, нажмите _Импортировать всё_, чтобы применить изменения
      конфигурации.
## Расширьте понимание

* Если изменения затрагивают только один элемент конфигурации (например,
  одно представление), можно воспользоваться одиночным экспортом/импортом
  конфигурации. См. [extend-deploy](./extend-deploy.md).
* После экспорта полной конфигурации из исходного сайта вы можете распаковать
  архив и зафиксировать его в системе контроля версий, например Git, чтобы
  отслеживать историю настроек. См. [extend-git](./extend-git.md).
