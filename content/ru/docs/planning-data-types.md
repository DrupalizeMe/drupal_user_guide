## Что такое сущность контента?

_Сущность контента_ (или просто _сущность_) — это единица данных, которая может включать текст, HTML-разметку, изображения, вложенные файлы и другие данные, предназначенные для отображения на сайте. Сущности контента могут быть определены ядром Drupal или модулями.

Сущности контента объединяются в _типы сущностей_ — каждая для своей цели и с разными вариантами отображения на сайте. Большинство типов сущностей также делятся на _подтипы сущностей_, что позволяет гибко варьировать назначение и отображение. Ниже — таблица некоторых распространённых типов сущностей:

| Тип сущности | Подтип | Модуль | Основное назначение |
| --- | --- | --- | --- |
| Материал | Тип материала | Node | Основное содержимое для вывода в центральной части страниц<br><br>*Пример:* На сайте городской ярмарки есть типы материала “Обычная страница”, “Производитель”, “Рецепт”. |
| Комментарий | Тип комментария | Comment | Комментарии к сущностям контента (обычно к материалам)<br><br>*Пример:* На блоге к постам добавляются комментарии. В примере ярмарки комментарии могут не использоваться. |
| Профиль пользователя | (нет) | User | Данные об учетной записи пользователя сайта<br><br>*Пример:* На любом сайте есть хотя бы имя пользователя и email; в соцсетях профиль может быть более подробным. |
| Пользовательский блок | Тип блока | Custom Block | Малые фрагменты текста или изображений, часто размещаемые в шапке, подвале или боковой колонке<br><br>*Пример:* На сайте ярмарки можно вынести часы работы и адрес в отдельный блок. |
| Термин таксономии | Словарь | Taxonomy | Используется для классификации других сущностей<br><br>*Пример:* Для рецептов можно создать словарь "Ингредиенты" с терминами “Морковь”, “Помидоры”; в блоге — “Теги” или “Категории”. |
| Файл | (нет) | File | Изображения или вложения, которыми управляет сайт и которые прикрепляются к другим сущностям<br><br>*Пример:* В материалах о рецептах и производителях можно размещать изображения, которые регистрируются как сущности Файл. |
| Контактная форма | Тип формы | Contact | Форма для связи с владельцами сайта<br><br>*Пример:* Для сайта ярмарки обязательно нужна контактная форма. |
## Что такое поле?

Данные в сущности хранятся в _полях_, каждое из которых содержит один определённый тип данных (отформатированный или простой текст, изображения, файлы, даты и т.п.). Типы полей могут быть определены ядром или модулями.

Поля добавляются администратором на уровне подтипа сущности — все сущности данного подтипа будут иметь одинаковый набор полей. Например, тип материала "Производитель" на сайте ярмарки может включать поля: название, логотип, сайт, описание; а тип "Обычная страница" — только заголовок и текст. При создании и редактировании сущностей вы задаёте значения для этих полей.
