## Мета { #user-new-user }

Створити аккаунт Постачальник для постачальників Солодкий мед і Веселий молочник.
## Необхідні знання

* [user-concept](./user-concept.md)
* [user-admin-account](./user-admin-account.md)
* [user-new-role](./user-new-role.md)
## Вимоги до сайту

Роль Постачальник повинна існувати на вашому сайті. Дивіться [user-new-role](./user-new-role.md).
## Кроки

1. У _Керування_ адміністративного меню, перейдіть в _Люди_ (_admin/people_).
1. Натисніть _Додати користувача_.
    ![Форма для створення нового облікового запису користувача](/images/user-new-user_form.webp)
1. Заповніть поля форми. Дивіться на таблицю нижче.

      <thead>
        <tr>
          <th>Назва поля</th>
          <th>Опис</th>

          <td>Адреса електронної пошти</td>

          <td>honey@example.com</td>
        </tr>
        <tr>

          <td>Солодкий мед</td>

1. Натисніть _Реєстрація_. Ви отримаєте повідомлення про створення призначеного для користувача
    аккаунта.
    ![Новий акаунт користувача був створений](/images/user-new-user-created.webp)
1. Створіть другий аккаунт Постачальник для Веселого молочника, виконавши дії, описані вище.
## Поліпшіть своє розуміння
