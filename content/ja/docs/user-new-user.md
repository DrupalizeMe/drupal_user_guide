## Goal { #user-new-user }

Create Vendor user accounts for Sweet Honey and Happy Farm vendors.
## Prerequisite knowledge

* [user-concept](./user-concept.md)
* [user-admin-account](./user-admin-account.md)
* [user-new-role](./user-new-role.md)
## Site prerequisites

The Vendor role must exist on your site. See [user-new-role](./user-new-role.md).
## Steps

1. In the _Manage_ administrative menu, navigate to _People_ (_admin/people_).
1. Click _Add user_.
    <img src="/images/user-new-user_form.png" alt="Form for creating a new user account" width="100%" />
1. Fill in the form fields. See the table below.
    <table>
      <thead>
        <tr>
          <th>Field name</th>
          <th>Explanation</th>
          <th>Example value</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td>Email address</td>
          <td>A valid email address for the vendor. All emails from the system will be sent to this address. The email address is not made public.</td>
          <td>honey@example.com</td>
        </tr>
        <tr>
          <td>Username</td>
          <td>A username for the vendor that they will use to sign in or author content items. Spaces are allowed; punctuation is not allowed except for periods, hyphens, apostrophes, and underscores.</td>
          <td>Sweet Honey</td>
        </tr>
        <tr>
          <td>Password</td>
          <td>A password the vendor will use to sign in to the site. You can see how safe the password is on the _Password strength_ gauge. You also get tips on how to make it safer.</td>
          <td>(Make a secure password)</td>
        </tr>
        <tr>
          <td>Confirm password</td>
          <td>Type the same password to avoid any typing mistakes.</td>
          <td>(Repeat password)</td>
        </tr>
        <tr>
          <td>Status</td>
          <td>Set the status of the user account. _Blocked_ users will not be able to sign in.</td>
          <td>Active</td>
        </tr>
        <tr>
          <td>Roles</td>
          <td>Set the role of the user account.</td>
          <td>Vendor</td>
        </tr>
        <tr>
          <td>Notify user of new account</td>
          <td>Whether or not to send a notification to the vendor's email address.</td>
          <td>Checked</td>
        </tr>
        <tr>
          <td>Picture</td>
          <td>Click _Browse_ and select a picture to upload. Pay attention to size restrictions.</td>
          <td>Photo of the vendor</td>
        </tr>
        <tr>
          <td>Contact settings</td>
          <td>Enable or disable the display of a contact form for the account.</td>
          <td>Checked</td>
        </tr>
      </tbody>
    </table>
1. Click _Create new account_. You will get a notification about the user account
    creation.
    <img src="/images/user-new-user-created.png" alt="New user account has been created" width="100%" />
1. Create a second Vendor account for Happy Farm by following the steps above.
