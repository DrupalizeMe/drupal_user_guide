[[install-prepare]]
=== Persiapan untuk Menginstal

[role="summary"]
Cara mengunduh perangkat lunak inti dan memenuhi prasyarat instalasi.

(((Mengunduh,perangkat lunak inti)))
(((Drupal core,mempersiapkan instalasi)))

==== Tujuan

Menguraikan langkah untuk mengunduh perangkat lunak inti dan menangani prasyarat
yang diperlukan.

==== Pengetahuan prasyarat

* Cara menginstal dan mengonfigurasi perangkat lunak server (jika menginstal di
  komputer sendiri)

* Cara menyiapkan hosting untuk situs web umum

* Cara membuat database

==== Prasyarat situs

Perangkat lunak server harus diinstal pada komputer tempat Anda berencana
meng-host situs. Lihat <<install-requirements>> untuk daftar persyaratan.

Lihat <<install-ddev>> untuk cara yang direkomendasikan untuk mulai menjalankan
perangkat lunak secara lokal.

Bergantung pada cara Anda berencana mengunduh perangkat lunak inti, Anda mungkin
perlu menginstal alat perangkat lunak tambahan terlebih dahulu. Lihat
<<install-decide>> dan <<install-tools>>.

==== Langkah-langkah

. Pilih metode untuk mengunduh dan menginstal perangkat lunak inti dari metode
yang tercantum dalam <<install-decide>>. Sisa petunjuk ini berlaku untuk opsi
Composer dan unduhan manual. Jika memilih opsi lain, seperti penginstal sekali
klik dari penyedia hosting, baca dokumentasi terkait untuk langkah tambahan.

. Siapkan URL dan hosting situs pada server. Pastikan hosting berfungsi dengan
meletakkan berkas HTML sederhana di direktori akar web hosting dan mengunjungi
URL situs.

. Buat database beserta akun pengguna database dengan akses penuh.

. Unduh berkas perangkat lunak inti ke direktori akar web menggunakan metode
yang telah dipilih. Lihat <<install-decide>> untuk tautan petunjuk.

==== Perluas pemahaman Anda

Lihat <<install-run>> untuk menjalankan penginstal interaktif.
