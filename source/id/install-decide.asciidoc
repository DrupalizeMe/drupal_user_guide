==== Metode apa yang tersedia untuk mengunduh perangkat lunak inti?

Sebelum dapat membangun situs, Anda harus terlebih dahulu mengunduh perangkat
lunak inti. Bergantung pada rencana Anda, ada beberapa cara untuk mengunduh
perangkat lunak inti:

Gunakan Composer::
  Jika Anda berencana membangun situs dan terus mengembangkannya dari waktu ke
  waktu, sebaiknya gunakan Composer untuk mengunduh perangkat lunak inti karena
  Composer akan mengelola dependensi dengan tepat. Jika Anda berencana
  menggunakan alat Drush (lihat <<install-tools>>), penggunaan Composer
  diperlukan. Lihat <<install-composer>> untuk petunjuk.

Cobalah demo daring gratis::
  Jika Anda sedang mengevaluasi apakah akan menggunakan Drupal untuk membangun
  situs, Anda dapat menggunakan penyedia daring untuk mendapatkan instalasi demo
  perangkat lunak inti dalam waktu 20 menit atau kurang. Lihat halaman
  https://www.drupal.org/try-drupal[_Drupal.org_ "Coba Drupal"].

Gunakan penginstal sekali klik dari penyedia hosting Anda::
  Jika Anda memilih untuk menginstal perangkat lunak inti di penyedia hosting,
  penyedia hosting tersebut mungkin memiliki dokumentasi khusus dan/atau
  penginstalan sekali klik yang dapat Anda gunakan. Lihat
  https://www.drupal.org/hosting[daftar penyedia hosting yang mendukung Drupal di _Drupal.org_].

Gunakan lingkungan yang telah dikonfigurasi::
  Gunakan lingkungan atau mesin virtual yang telah dikonfigurasi, yang berisi
  Drupal dan semua perangkat lunak pendukung yang diperlukan, untuk menginstal
  Drupal secara lokal. Lihat bagian untuk sistem operasi Anda di
  https://www.drupal.org/docs/develop/local-server-setup[halaman dokumentasi
  komunitas _Drupal.org_ "Panduan penyiapan server lokal"] untuk mengetahui
  pilihan yang tersedia.

==== Apa yang terjadi ketika saya menginstal perangkat lunak inti?

_Menginstal_ perangkat lunak inti berarti menyiapkan beberapa tabel database,
konfigurasi, dan akun pengguna administratif agar Anda dapat membangun dan
menggunakan situs.

==== Metode apa yang tersedia untuk menginstal perangkat lunak inti?

Ada beberapa cara untuk menginstal perangkat lunak inti:

Penginstal di balik layar::
  Jika Anda memilih menggunakan demo daring atau penginstal sekali klik dari
  penyedia hosting, perangkat lunak inti mungkin diinstal secara otomatis untuk
  Anda.

Penginstal interaktif::
  Perangkat lunak inti memiliki penginstal interaktif yang menyajikan beberapa
  formulir daring, lalu menyelesaikan penginstalan menggunakan informasi yang
  Anda masukkan dalam formulir tersebut. Lihat <<install-prepare>> dan
  <<install-run>>.

Alat baris perintah::
  Alat baris perintah (lihat <<install-tools>>) juga dapat digunakan untuk
  melakukan langkah penginstalan.

Penginstal situs demo::
  Buat situs demo sementara dengan cepat yang menggunakan server web bawaan dan
  database SQLite, yang merupakan bagian dari PHP, dengan menjalankan perintah
  berikut dari direktori akar proyek. Dalam kasus ini, Anda tidak akan
  menjalankan penginstal interaktif. Lihat
  https://www.drupal.org/docs/official_docs/evaluator-guide[Panduan Evaluator]
  untuk mempelajari lebih lanjut.

  ----
  php -d memory_limit=256M core/scripts/drupal quick-start demo_umami
  ----
