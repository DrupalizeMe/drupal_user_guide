==== ¿Qué son las distribuciones?

Las _distribuciones_ proporcionan características y funcionalidades para un tipo
específico de sitio web a modo de una única descarga que contiene el núcleo de
software, los módulos contribuidos, los temas y una configuración predefinida.
Una distribución hace posible configurar un sitio web complejo para un propósito
específico en menos pasos que instalando y configurando los elementos de forma
individual.

Principalmente, hay dos tipos de distribuciones:

Distribuciones de funcionalidad completa::
  Una distribución de funcionalidad completa es un proyecto que proporciona una
  solución completa para configurar un sitio web con un propósito especializado,
  como puede ser académico, de negocios, gubernamental, sin ánimo de lucro,
  editorial, social, etc. Por ejemplo, podría usar una distribución existente
  para mercados de agricultores para construir su propio sitio web, o podría
  compartir su configuración del sitio del mercado de agricultores como una
  distribución para que otros la utilicen.

Otras distribuciones::
  Las distribuciones también pueden ser herramientas de inicio rápido que los
  desarrolladores y _site-builders_ pueden usar como punto de partida.
