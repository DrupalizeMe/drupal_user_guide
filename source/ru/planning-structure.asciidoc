[[planning-structure]]
=== Проектирование структуры контента

[role="summary"]
Как спланировать структуру сайта: какие типы и подтипы сущностей использовать для разных видов контента, и какие страницы будут содержать списки материалов.

(((Структура контента, планирование)))
(((План сайта, структура контента)))

==== Цель

Составить план структуры контента сайта (какие типы и подтипы сущностей использовать для разных видов контента), а также определить, на каких страницах будут выводиться списки материалов.

==== Необходимые знания

* <<planning-data-types>>
* <<planning-modular>>
* <<preface-scenario>>

==== Шаги

. Определите, какой контент должен быть на сайте. Подумайте, какую информацию будут искать посетители, а также что вы сами хотите им показать. Получившийся список может выглядеть так, как в разделе <<preface-scenario>>.

. Для каждого типа информации решите, какой тип сущности Drupal подходит лучше всего. Важно учитывать, где и как контент будет использоваться и кем редактироваться. Например, на сайте городского рынка часы работы и адрес лучше всего оформить как отдельный пользовательский блок, чтобы разместить его в боковой колонке на всех страницах. А страницы производителей удобнее сделать как материалы (node), чтобы каждый производитель мог редактировать свои данные — права доступа ядра Drupal это позволяют.
+
Обратите внимание, что иногда нет единственно правильного варианта: например, производителей можно реализовать как отдельные пользовательские профили, но тогда страница производителя будет жестко связана с определенной учетной записью, и поменять владельца такой страницы будет сложнее.

. Для каждого выбранного типа сущности определите, какие подтипы нужны. В нашем примере с рынком для сущности “Материал” (Content item) могут быть подтипы “Обычная страница” (например, Главная и О сайте), “Производитель” и “Рецепт”.

. Для каждого подтипа продумайте необходимые поля. Например, для “Производителя” понадобятся поля: имя, URL сайта, изображение и описание.

. Определите, какие списки материалов нужны на сайте: это могут быть отдельные страницы или блоки в определенных областях. Для каждого списка решите, какие материалы туда будут попадать, в каком порядке и с какими фильтрами. Например, для страницы рецептов удобно сделать фильтрацию по ингредиентам, а значит, у типа материала “Рецепт” должно быть поле “Ингредиенты”.

. Для каждого поля определите его тип (текст, форматированный текст, дата, изображение и т. д.) и количество значений. Большинство полей бывают однозначными, но, например, для ингредиентов в рецепте понадобится множественное поле.

. Подумайте, какие поля стоит сделать ссылками на термины таксономии (то есть выбирать значения из заранее определенного списка). Это удобно для значений, которые могут регулярно пополняться. Например, ингредиенты для рецепта — отличный кандидат для таксономии.

. Если необходимо, определите поля-ссылки на другие сущности контента. Например, если производители будут отправлять рецепты, добавьте в “Рецепт” поле-ссылку на материал “Производитель”, чтобы связать рецепт и его автора.

Пример итоговой структуры для сайта городского рынка:

[width="100%",frame="topbot",options="header"]
|=============================================
|Тип сущности |Подтип |Примеры |Поля

|Материал |Обычная страница |Главная, О сайте |Заголовок, тело страницы

|Материал |Производитель |Страница каждого производителя |Имя, описание, изображение, ссылка на сайт

|Материал |Рецепт |Страница каждого рецепта |Название, описание, изображение, ссылка на производителя, ингредиенты (таксономия)

|Пользовательский блок |(общий) |Копирайт в подвале, часы и адрес на боковой панели |Без дополнительных полей

|Термин таксономии |Ингредиенты |Морковь, помидоры и т.д. |Без дополнительных полей

|Контактная форма |(общая) |Страница обратной связи |Имя, email, тема, сообщение

|Профиль пользователя |— |Не выводится на сайте |Без дополнительных полей

|=============================================

Списки материалов, которые понадобятся:

[width="100%",frame="topbot",options="header"]
|=============================================
|Страница или область |Тип и подтип сущности |Фильтр/сортировка/пагинация |Поля для отображения

|Страница производителей |Материалы типа Производитель |Все, по алфавиту, постранично |Изображение, имя, сокращенное описание

|Страница рецептов |Материалы типа Рецепт |Фильтр по ингредиентам, по алфавиту, постранично |Изображение, название

|Блок “Недавние рецепты” |Материалы типа Рецепт |Последние 5 |Изображение, название

|=============================================
